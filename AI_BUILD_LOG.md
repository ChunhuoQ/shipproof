# AI Build Log

## Brief

Build an OPC / Autonomous Agents entry for BUIDL_QUESTS 2026 with a real public workflow,
clear boundaries, and a 60-second demo that does not depend on imagined future features.

## Product selection

AI reviewed the official tracks, submission window, live OpenArena field, and prior
hackathon judge data. A recurring failure pattern was stronger than any single product
category: impressive submissions lost credibility through dead demos, private repos,
unsupported claims, missing runbooks, and unclear safety boundaries.

ShipProof was selected because it turns that pattern into a focused Agentic Service with
an immediate user, a measurable result, and a demo that can prove its own value.

## AI-assisted work

1. Extracted the official deadline, tracks, and public submission requirements.
2. Compared candidate ideas against remaining implementation time and existing code.
3. Designed the seven-check scoring contract and fail-closed verdicts.
4. Implemented GitHub and demo probes, SSRF protection, evidence normalization, repair
   findings, report fingerprints, and linked audit receipts.
5. Rebuilt the web experience around a single cold-open workflow.
6. Generated unit tests for ready/blocked verdicts, hard gates, URL security, and audit
   integrity.
7. Produced the architecture, honest limitations, demo script, and submission copy.

## Human role

The human selected ShipProof, chose the OPC / Autonomous Agents direction, and set the
competitive goal. Deployment-account actions, public posting, and final positioning
remain human-controlled.

## Boundary decisions

- ShipProof never describes keyword detection as proof that a product claim is true.
- The receipt is described as a tamper-evident application proof, not a blockchain proof.
- The server refuses local/private network targets even if that makes some demos
  impossible to scan.
- A language model is not allowed to override hard-gate evidence.
